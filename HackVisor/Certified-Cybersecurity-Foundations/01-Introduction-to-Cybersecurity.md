\## Overview



This module introduced the fundamentals of cybersecurity and provided an overview of different cybersecurity areas, career paths, types of hackers, and penetration testing.

\---



\## Topics Learned



\### 1. Types of Hackers



I learned about different types of hackers and their purposes, including:



\- White Hat Hackers

\- Black Hat Hackers

\- Grey Hat Hackers



Understanding the differences between these types of hackers helps distinguish authorized security testing from unauthorized or malicious activities.



\---



\### 2. Sub-Fields of Cybersecurity



I learned that cybersecurity consists of multiple specialized areas.



Some of the areas introduced in the module include:



\- Security Operations

\- Penetration Testing

\- Digital Forensics

\- Incident Response

\- Network Security

\- Application Security



Each area focuses on different aspects of protecting organizations and responding to security threats.

\### 3. Cybersecurity Careers



The module introduced different cybersecurity career paths and the roles available within the industry.



Examples include:



\- SOC Analyst

\- Security Analyst

\- Penetration Tester

\- Incident Responder

\- Digital Forensics Analyst

\- Security Engineer



This helped me understand the different career options available in cybersecurity and the skills associated with each area.



\---



\### 4. Introduction to Penetration Testing



I learned the basic purpose of penetration testing and how security professionals assess systems for security weaknesses in an authorized environment.



A typical penetration testing process may involve:



1\. Planning and Scoping

2\. Reconnaissance

3\. Scanning and Enumeration

4\. Vulnerability Identification

5\. Exploitation

6\. Reporting



Penetration testing helps organizations identify weaknesses before they can be exploited by malicious attackers.



\---



\## Security Relevance



Understanding cybersecurity fundamentals provides a foundation for both offensive and defensive security.



For example, understanding penetration testing can help defensive security teams understand how vulnerabilities may be discovered and exploited.



Similarly, understanding different cybersecurity fields helps security professionals identify where activities such as monitoring, investigation, vulnerability assessment, and incident response fit within an organization's security operations.



\---



\## Key Takeaways



\- Cybersecurity consists of multiple specialized fields.

\- Different types of hackers have different intentions and authorization levels.

\- Penetration testing is performed to identify security weaknesses in authorized environments.

\- Cybersecurity offers a wide range of career paths.

\- Understanding cybersecurity fundamentals is important before progressing into more specialized security areas.
